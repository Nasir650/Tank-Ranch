Approved Tech Stack

Built on one proven, lightweight stack

No bulky page builders. No proprietary locking mechanisms. Clean code designed for maximum speed and machine readability.

Swipe horizontally to inspect stack layers →
Stack Layer Technology Choice Engineering Justification
CMS WordPress Core Fast to template, easy to hand off, zero vendor lock-in. Client owns full admin access.
Theme GeneratePress / Kadence Ultra-lightweight baseline. Zero page-builder bloat (no Elementor or Divi drag-and-drop sluggishness).
Structured Fields Advanced Custom Fields (ACF) Pro Every service, town, and FAQ entered once as fields. Pages and schema generated from the same data. This is the Answer Map.
Schema Layer Rank Math Pro + Custom JSON-LD Organization, LocalBusiness, Service, FAQPage, Article, and BreadcrumbList nodes connected directly.
CDN & Security Cloudflare SSL, bot protection, and edge caching.
Forms Gravity Forms Routes client-site inquiries to email or a CRM.
Call Tracking CallRail Dynamic Insertion Dynamic number swapping on desktop and mobile. Calls and recordings are the primary numbers we report.
AI Readability llms.txt + Structured Answer Cards A root-level text file can point readers to key pages. Short answer blocks make the content easier to scan.
